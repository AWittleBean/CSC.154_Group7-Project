# CSC.154_Group7-Project

### Local Environment Setup Instructions
All project work should be done within a local virtual environment to ensure consistency in shared tool usage.


Create your virtual environment at the projects source using the following command in your terminal:  
```py -m venv .venv``` in Windows, or  
```python3 -m venv .venv``` in macOS/Unix.


After creating your venv, activate it by using the following command in your terminal:  
```.venv\Scripts\activate``` in Windows, or  
```source .venv/bin/activate``` in macOS/Unix.


To install the required packages for the project, run the following command in your terminal:  
```py -m pip install -r requirements.txt``` in Windows, or  
```python3 -m pip install -r requirements.txt``` in macOS/Unix.
